# BMS Control Desk Changelog

本文档只记录 CAN 上位机已经完成的功能与修正。固件协议变化仍记录在项目根目录的进度和固件文档中。

## 2026-08-03

### 参数页和 Windows 发布入口收紧

- 参数页压缩标题、输入框、开关行和维护命令行的高度；“系统参数与维护命令”和“需要谨慎的操作”拆成左右两个同级面板，Flash 保存状态移到顶部命令条件栏。
- 充电请求回读拆成“请求值”和“充电机反馈”两个字段，分别表示主控保存的请求值与 Legacy/Chroma 充电机返回的实际值。
- 源码运行仍保留内置模拟数据供开发；PyInstaller 发布版固定使用真实 PCAN，隐藏工作模式选择并排除模拟器模块。发布版使用说明补充 Python、PCAN-Basic/驱动和 WebView2 的安装边界。

### 状态机、IMD 和保存状态再次精简

- 状态机改为“状态机”标题在上、DOC/代码短状态名在下的纵向布局，使用 `SELF_TEST`、`STANDBY`、`PRECHARGE`、`HV_ON`、`FAULT` 并按状态着色。
- IMD 总览只保留 `OK_HS` 正常/故障、实际 PWM 频率、占空比和绝缘阻值；DCP、SST 等模式通过简短悬浮提示说明，不再铺开“有信号/有效/通过”重复字段。
- 保护开关显示 DOC 中的 CLI 短名，完整变量名放在悬浮提示中。悬浮提示只说明字段含义或缩写，不展示实现层面的无效值和兜底处理。
- 配置、告警开关、充电请求、电流方向和充电机类型写入后，界面继续读取主控保存状态；仍在保存时显示等待，保存等待位清除后显示“已保存到 Flash”。模拟器同步覆盖保存等待和完成状态。

### 状态机视觉样式统一

- 移除状态机信息条独有的彩色左侧竖条和动态颜色变量，恢复与其他卡片一致的普通边框、圆角和间距。

### 总览信息层级二次修正

- 高压输出直接用三个等宽状态格显示主正、主负和预充继电器，移除“继电器控制命令”等不能增加信息的小标题；请求、安全回路和最近一次预充保留为紧凑字段表。
- 温度与冷却、绝缘监控（IMD）拆成两个独立卡片；IMD 标题、状态值和 PB8/PWM/阻值/绝缘判定的字重与字号统一提高，避免诊断结果被小字淹没。
- 充电计时卡片只显示已计时和预计剩余时间；平均充电电流仍只作为后台估算输入，不再占用总览空间。
- 修正无数据时把 `0x00000000`、无活动告警或未充电显示成确定状态的问题；故障、告警等级、继电器命令、温度/风扇和 IMD 报文超过 1.5 s 后统一显示等待数据，顶部告警颜色也恢复为绿色/黄色/红色状态提示。
- 充电计时改为每次轮询都推进，不因切换到其他页面而漏计；内置模拟数据的高压阶段增加 `charge_mode=1` 和正向充电电流，能够复现计时与预计剩余显示。
- 将“安全状态优先、主题单一、状态值醒目、按内容分配空间、只保留现场需要的信息”写入项目 `AGENTS.md` 与上位机 `README.md`，作为后续界面修改的检查依据。

### 状态信息和页面布局整理

- 删除左下角“FORMULA STUDENT”文字，保留 BITFSAE 标志；左下角将上位机版本和日期合并为一行，并改为显示硬件 PCB V3.0（2026-05-30）。
- 移除每个页面共用的顶部标题和解释栏，把连接设备/模式按钮移到底部状态栏。
- 固件身份显示变体、Git 标识和北京时间构建日期，不再显示构建工作区的“未提交改动”；底部不再显示状态帧年龄。状态帧新鲜度判断仍在后台保留。

### 品牌、趋势图和界面一致性

- 左下角文字标志替换为 BITFSAE 官方标志（亮色字标），侧栏顶部使用银鲨图标。
- 趋势图重做为包电压、总电流和 PRE 电压三线双轴曲线：左右轴带刻度标签、时间轴、零线、渐变填充和末端数据点，图例实时显示当前值；模拟数据也输出 PRE 电压。
- 单体页异常框改为外扩描边，相邻异常单体共用连续红色轮廓，不再出现红框之间的深色间隙。
- 统一按钮尺寸：主操作按钮不再独占整行，改为与页面右对齐的紧凑按钮，与“立即校时”“写入”等操作按钮一致。
- 参数页告警开关行增加状态圆点和“启用/关闭”文字，启用行使用绿色状态（与故障页保护开关一致），修改后显示“待写入”。
- 底部状态栏统一为单行：连接项显示工作模式、总线用途和位率；RX/TX、固件身份和记录状态使用统一层级，回放使用黄色状态点，Legacy CANB 不重复显示 250k。
- 移除工程参数文件（`.bmsproj`）功能：按钮、对话框、导出/导入接口和对应测试一并删除，简化顶部栏。
- 固件新增独立构建日期帧`0x186C51F4`（经典CAN DLC 8：年-2000、月、日，北京时间），与身份帧同时发送；状态栏固件信息显示“变体 · Git · 构建日期”，旧固件不发该帧时不显示日期。
- 首次验证 macOS 源码运行：Homebrew Python 3.14 虚拟环境安装 pywebview 6.2.1 与 python-can 4.6.1，`python -m TOOLS.bms_host` 正常打开原生窗口；macOS 无 PEAK 驱动，只能使用内置模拟数据。

### 故障页和界面缩放复核

- 重做“故障与记录”页：删除告警卡片内重复出现的序号和bit文字，改为直接显示主控阈值、固件固定条件及确认/清除时间；一级、二级、故障码置位、正常和保留项使用统一且可辨认的状态样式。
- 保护开关改为四列对齐的“启用/关闭”状态表，增加启用数量和回报版本汇总；启用项使用明确的绿色状态，关闭项降低层级。
- 默认界面缩放调整为110%，`Ctrl+0`恢复110%；修复放大后工作区仍按未缩放的100vh计算、导致底部状态栏和下方内容超出可视区的问题。
- 告警等级帧和保护开关帧未收到时明确显示“等待等级/等待回报”，不再把尚未收到的数据误显示成“正常”或“关闭”。
- 重整总览信息分组：高压链路、温度/风扇和 IMD 分开显示，详细字段见 `README.md` 的“运行总览”。
- 再次压缩总览首屏：缩短状态条、KPI、表头和数据行，降低次级说明字号，删除高压卡片常驻解释文字，并缩短趋势图高度，让更多重要状态在首屏可见。
- 完善 IMD `0x186850F4` 解析：读取 PB8、PWM、阻值有效、绝缘通过等 Byte1 位；PWM 无效时隐藏频率/占空比，阻值无效时显示 `—`，`0xFFFF` 饱和阻值显示 `≥65535 kΩ`，并对 IMD 帧增加新鲜度判断。

## 2026-08-02

### 界面结构和交互复核

- 删除每个模组内部重复占行的“电压”“温度”标题；放大全包统计值，并把四项保护阈值改为独立、清晰的状态条。
- 增加应用内页面缩放处理，修复部分Windows WebView2窗口设置`zoomable=True`后`Ctrl++`仍无响应的问题；现在明确捕获主键盘和数字键盘的加减号、`Ctrl+0`及`Ctrl+鼠标滚轮`，缩放范围80%..130%并记住比例。
- 重新整理电芯与温度页的信息层级：正常模组不再反复显示“数据完整”，只有通信中断或数据缺失时才突出提示；去掉重复的全局编号范围，单路编号改为模组内 `C1..C23` 和 `T1..T8`。
- 电芯页顶部只保留最高、最低、压差和温差等直接用于判断的值，完整性仅在缺失时提示；模组标题改为电压范围、压差和温度范围，并放大单路数值与标签；温差统一保留一位小数，避免浮点尾数直接显示。
- 将工具运行产生的 `.mcp-npm-cache` 加入忽略列表，并撤销与本次上位机运行和界面修正无关的打包脚本改动，减少工作区噪声。
- 恢复包电压/总电流双轴趋势曲线；新增从检测到充电模式开始的本次计时，并按16.2Ah、SOC和本次平均充电电流显示预计剩余时间与预计充满时刻。
- 统一放大页面标题、导航、区块标题、表格、状态值、输入框和按钮的字号与行高，消除同级组件大小不一致的问题；1120×720仍无水平溢出。
- 重新划分文档职责：项目`DOC/CAN上位机.md`只保留主控接口、安全边界和项目级验证入口；完整界面、操作、映射、记录和排错说明统一维护在本目录`README.md`。
- 将信息架构分成四个只读监视页和一个“参数与命令”写入页；读取Flash日志保留在故障页，所有会改变主控状态或参数的操作集中到写入页。
- 总览改为现场状态表：状态机、故障码与解析、包电压/电流、PRE电压、压差、SOC、继电器、HV_ACC、充电信号、安全回路、预充耗时、六个模组平均值、风扇和IMD；删除从控完整性卡片和SOP面板，保留电压/电流趋势曲线。
- 138串电压和48路温度改为每个BMU内同页并列显示，顶部同时显示主控当前阈值。
- 删除侧栏选中竖条、选中背景框和同类装饰性竖线；左下角增加BITFSAE、软件版本、版本日期和目标主控。
- 修复PyWebView启动后递归扫描原生WinForms窗口的问题：后台服务和窗口引用改为私有成员，不再通过JavaScript API暴露`AccessibilityObject`，避免`TYPE_E_CANTLOADLIBRARY`和递归深度溢出导致界面卡死。
- 前端状态读取改为单次完成后再安排下一次，禁止250ms轮询重叠；总览保持250ms，其余详细页使用500ms，窗口隐藏时使用1000ms。每轮只更新当前页面需要的内容。
- 将界面调整为紧凑的现场仪表结构，减少重复容器、过大圆角、分散间距和装饰性动画。
- 总览按主控状态、四个关键量、高压链路、从控、活动告警和诊断分项组织信息。
- 单体页在宽窗口按8列显示电压，并在“只看异常 / 缺失”时隐藏全部正常的从控分组；全部正常时只显示一次结果。
- 告警矩阵在宽窗口使用4列，较窄窗口使用3列；每项在固定位置显示名称、判定条件和状态。
- CAN监视器改为报文表在窗口剩余区域内独立滚动，搜索、筛选、暂停、记录和回放操作保持可见。
- 修复长页面切换到短页面时沿用旧滚动位置，导致新页面看起来空白的问题。
- 修复充电机类型选择在发送前被250ms周期回报立即覆盖的问题。
