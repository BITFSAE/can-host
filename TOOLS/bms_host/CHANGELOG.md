# BMS Control Desk Changelog

本文档只记录 Windows CAN 上位机已经完成的功能与修正。固件协议变化仍记录在项目根目录的进度和固件文档中。

## 2026-08-03

### 故障页和界面缩放复核

- 重做“故障与记录”页：删除告警卡片内重复出现的序号和bit文字，改为直接显示主控阈值、固件固定条件及确认/清除时间；一级、二级、故障码置位、正常和保留项使用统一且可辨认的状态样式。
- 保护开关改为四列对齐的“启用/关闭”状态表，增加启用数量和回报版本汇总；启用项使用明确的绿色状态，关闭项降低层级。
- 默认界面缩放调整为110%，`Ctrl+0`恢复110%；修复放大后工作区仍按未缩放的100vh计算、导致底部状态栏和下方内容超出可视区的问题。
- 告警等级帧和保护开关帧未收到时明确显示“等待等级/等待回报”，不再把尚未收到的数据误显示成“正常”或“关闭”。

## 2026-08-02

### 界面结构和交互复核

- 删除每个模组内部重复占行的“电压”“温度”标题；放大全包统计值，并把四项保护阈值改为独立、清晰的状态条。
- 增加应用内页面缩放处理，修复部分Windows WebView2窗口设置`zoomable=True`后`Ctrl++`仍无响应的问题；现在明确捕获主键盘和数字键盘的加减号、`Ctrl+0`及`Ctrl+鼠标滚轮`，缩放范围80%..130%并记住比例。
- 重新整理电芯与温度页的信息层级：正常模组不再反复显示“数据完整”，只有通信中断或数据缺失时才突出提示；去掉重复的全局编号范围，单路编号改为模组内 `C1..C23` 和 `T1..T8`。
- 电芯页顶部只保留最高、最低、压差和温差等直接用于判断的值，完整性仅在缺失时提示；模组标题改为电压范围、压差和温度范围，并放大单路数值与标签；温差统一保留一位小数，避免浮点尾数直接显示。
- 将工具运行产生的 `.mcp-npm-cache` 加入忽略列表，并撤销与本次上位机运行和界面修正无关的打包脚本改动，减少工作区噪声。
- 恢复包电压/总电流双轴趋势曲线；新增从检测到充电模式开始的本次计时，并按16.2Ah、SOC和本次平均充电电流显示预计剩余时间与预计充满时刻。
- 统一放大页面标题、导航、区块标题、表格、状态值、输入框和按钮的字号与行高，消除同级组件大小不一致的问题；1120×720仍无水平溢出。
- 重新划分文档职责：项目`DOC/CAN上位机.md`只保留主控接口、安全边界和项目级验证入口；完整界面、操作、映射、记录和排错说明统一维护在本目录`README.md`。
- 将信息架构分成四个只读监视页和一个“参数与命令”写入页；读取Flash日志保留在故障页，所有会改变主控状态或参数的操作集中到写入页。
- 总览改为现场状态表：状态机、故障码与解析、包电压/电流、PRE电压、压差、SOC、继电器、HV_ACC、充电信号、安全回路、预充耗时、六个模组平均值、风扇和IMD；删除从控完整性卡片和SOP面板，保留电压/电流趋势曲线。
- 138串电压和48路温度改为每个BMU内同页并列显示，顶部同时显示主控当前阈值。
- 删除侧栏选中竖条、选中背景框和同类装饰性竖线；左下角增加BITFSAE、软件版本、版本日期和目标主控。
- 修复PyWebView启动后递归扫描原生WinForms窗口的问题：后台服务和窗口引用改为私有成员，不再通过JavaScript API暴露`AccessibilityObject`，避免`TYPE_E_CANTLOADLIBRARY`和递归深度溢出导致界面卡死。
- 前端状态读取改为单次完成后再安排下一次，禁止250ms轮询重叠；总览保持250ms，其余详细页使用500ms，窗口隐藏时使用1000ms。每轮只更新当前页面需要的内容。
- 将界面调整为紧凑的现场仪表结构，减少重复容器、过大圆角、分散间距和装饰性动画。
- 总览按主控状态、四个关键量、高压链路、从控、活动告警和诊断分项组织信息。
- 单体页在宽窗口按8列显示电压，并在“只看异常 / 缺失”时隐藏全部正常的从控分组；全部正常时只显示一次结果。
- 告警矩阵在宽窗口使用4列，较窄窗口使用3列；每项在固定位置显示名称、判定条件和状态。
- CAN监视器改为报文表在窗口剩余区域内独立滚动，搜索、筛选、暂停、记录和回放操作保持可见。
- 修复长页面切换到短页面时沿用旧滚动位置，导致新页面看起来空白的问题。
- 修复充电机类型选择在发送前被250ms周期回报立即覆盖的问题。

### 当前验证

- 上位机协议和PyWebView API暴露测试16项通过。
- JavaScript语法、HTML ID引用和差异格式检查通过。
- Chromium模拟快照检查五页导航、138串渲染、异常筛选、确认弹窗、工程弹窗和CAN列表滚动，无脚本错误。
- 1460×920和1120×720窗口无水平溢出。

## 2026-08-02（初始实现和协议扩展）

- 新增PyWebView Windows上位机、独立CAN接收线程和内置模拟数据。
- 完成CAN1 138串/48路温度、主控状态、高压、IMD、SOP、32项告警、故障码变化记录、阈值、19个开关、充电请求和维护命令。
- 支持CANB 500 kbit/s、Legacy CANB 250 kbit/s、`.bmslog`/CSV记录与历史回放、`.bmsproj`工程导入导出。
- 接入版本3工具命令、统一应答、固件身份、充电机反馈、IVT/SOC诊断和Flash重要故障日志读取。
