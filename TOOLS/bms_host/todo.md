# BMS Control Desk TODO

本文档只记录 CAN 上位机的剩余工作、风险和验证结果。上位机进度、风险和验证以本文件为准，不在根目录 `todo.md` 重复登记；只有影响 F405 固件协议、安全行为或跨层联调的结论，才由根目录 `todo.md` 记录固件侧摘要。已经完成的变化写入 [`CHANGELOG.md`](CHANGELOG.md)，当前功能和操作方法见 [`README.md`](README.md) 与 [`../../DOC/CAN上位机.md`](../../DOC/CAN上位机.md)。

## 当前状态

- CAN1、CANB 500 kbit/s、Legacy CANB 250 kbit/s和内置模拟数据已经接入。
- 已实现138串电压、48路温度、主控总览、故障与记录、独立参数与命令页、CAN记录/回放；高压、温度/冷却和 IMD 已按现场判断顺序分成直接可读的卡片。具体字段见 [`README.md`](README.md)。
- 在线写命令逐次确认，并核对总线、主控状态、请求计数、命令码和统一应答。
- 界面采用紧凑的现场仪表布局，连接按钮位于底部状态栏，参数页使用左右同级维护面板，页面不再设置统一标题栏，支持1120×720最小窗口和`Alt+1..5`切页。
