# BMS Control Desk TODO

本文档只记录 Windows CAN 上位机的剩余工作、风险和验证结果。已经完成的变化写入 [`CHANGELOG.md`](CHANGELOG.md)，当前功能和操作方法见 [`README.md`](README.md) 与 [`../../DOC/CAN上位机.md`](../../DOC/CAN上位机.md)。

## 当前状态

- CAN1、CANB 500 kbit/s、Legacy CANB 250 kbit/s和内置模拟数据已经接入。
- 已实现138串电压、48路温度、主控总览、故障与记录、独立参数与命令页、CAN记录/回放及工程文件。
- 在线写命令逐次确认，并核对总线、主控状态、请求计数、命令码和统一应答。
- 界面采用紧凑的现场仪表布局，支持1120×720最小窗口和`Alt+1..5`切页。
