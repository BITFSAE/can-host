# CAN 上位机与工具使用

本文说明车队 CAN 上位机（BITFSAE CAN HOST）各页面的职责、连接方法、接口边界和现场验证：BMS 监视四页、整车总览、整车风扇、台架模拟从控和 IVT 配置。

帧格式的权威来源按接口分仓库：BMS 帧以 BMS-MASTER-F405 仓库 `DOC/CAN通信协议.md` 和固件 `App/bms_can_protocol.c` 为准；FanController 帧以 FanController 仓库 `Doc/风扇控制.md` 和 `Core/Src/fan_controller.c` 为准；PDM 帧以 PDM 仓库 `Doc/CAN接口.md` 和 `Core/Src/pdm_monitor.c` 为准；整车各节点的中央 DBC 登记在 vehicle-interfaces 仓库 `can/Vehicle_CanB.dbc`。两边不一致时以固件为准，同步修改本仓库实现、测试和 vehicle-interfaces。IVT 目标配置的完整表格在 BMS-MASTER-F405 仓库 `DOC/IVT能量计配置与CANB切换.md`。

上位机安装、源码运行和 Windows 发布见本仓库 [`README.md`](../README.md)。上位机进度、风险、验证和已完成变更只维护在本仓库 [`todo.md`](../todo.md)。

## 1. 工具职责和连接关系

### BMS 监视四页

运行总览、电芯与温度、故障与记录、参数与命令用于读取 F405 当前状态、查看单体和温度、查看故障、发送 F405 工具命令以及记录/回放 CAN 数据。主监视连接可选 CAN1 或 CANB；CANB 上没有 138 串电压和 48 路温度的原始从控报文，相关区域显示“等待数据”。

### 整车总览与整车风扇

整车总览在一个独立 CANB 连接上集中显示整车侧节点：SOP 限功率（0x4A0/0x4A3/0x4A4）、BMS 整车镜像（0x4B0/0x4B1）、自有 IVT-S 八通道（0x512–0x519）、赛会能量计（0x521/0x522/0x526/0x528）、PDM 低压两侧（0x5A0/0x5A1）、ECU 四轮调试帧（0x502/0x505–0x509）和轮胎温度（0x071–0x074）。

整车风扇页面共用同一条整车连接，查看 FanController 的三路转速、两路占空比、温度与故障，并发送模式、自动温控曲线和失联策略命令。命令带 CRC-8 并等待 FanController 按操作码和序号应答。

整车连接与 BMS 主监视连接互相独立：可以主监视接 CAN1 调 F405 参数，同时整车连接接 CANB 看低压和高压数据，底部快捷栏同时显示两条连接的常用值。

### 台架模拟从控

台架模拟从控用于给 F405 的 CAN1 提供六个从控的测试报文，验证接收、完整性判断、告警和从控离线处理。它复用 `cli/pcan_bms_bench.py` 的模型和命令。页面只负责连接、发送和显示状态，不改变 F405 Flash，也不伪造 IVT、充电机或 IMD 数据。

### IVT 配置

IVT 配置用于首次安装或维护真实 IVT-S。它在 IVT 所在 CANB 上读取配置，判断当前设备是否已经与 F405 目标一致，并在需要时完成一次性配置或切换 250/500 kbit/s 位率。它使用自己的独立连接，与整车连接互不影响。

台架和 IVT 配置收在左侧“工程工具”折叠项中，这两页隐藏底部状态栏以获得最大工作区。日常监视不会自动打开这些页面。

## 2. 总线用途和安全边界

| 总线选项 | 位率 | 用途 | 上位机发送范围 |
|---|---:|---|---|
| CAN1 | 500 kbit/s | 从控原始采样、主控周期状态、F405 工具命令与应答 | F405 工具命令；台架页发送从控帧 |
| CANB | 500 kbit/s | BMS 状态/故障/告警、SOP、IVT、赛会能量计、PDM、FanController、ECU、胎温 | IVT 厂商配置命令；整车风扇命令 `0x5A4` |
| CANB Legacy | 250 kbit/s | Legacy 充电机和 BMS 状态/故障/告警 | IVT 厂商配置命令；整车风扇命令 `0x5A4` |

- 接口定义以 vehicle-interfaces 的 DBC 做团队中央登记，以各固件仓库的实现为最终依据；本仓库解析代码（`canhost/decoders.py`）与测试和两边保持同步。
- F405 工具命令只从 CAN1 发送。整车连接是只读监视加 FanController 命令；BMS、ECU、Chroma 和 Legacy 报文按各自接收路径处理。
- IVT 配置使用独立的 Command/Response ID。配置前先确认 PCAN 位率与 IVT 当前位率一致，并确认 CANB 上只有目标 IVT。
- 台架模拟从控工具只在自己的 CAN1 连接上发送六个从控帧；它不发送 IVT 结果帧。模拟数据、历史回放和 BMS 主监视连接都不能执行 IVT 配置。
- 阈值、告警开关、充电请求、电流方向、充电机类型、RTC、Flash 日志清除、故障复位和全部整车风扇命令都要求逐次确认。电池箱内风扇由 F405 主控自动控制并经 CAN1 `0x186250F4` 上报，上位机只显示、不远程命令。
- 风扇命令发给整车 CANB 上的 FanController，与 F405 主控无关。手动/关闭模式必须带 1..60 秒有效时间，到期 FanController 自动回到自动温控；需要保持手动转速时由操作者按短于有效时间的间隔重发，上位机不做自动续发。温控曲线和失联策略只保存在 FanController 的 RAM 中，复位后恢复默认。
- 所有 F405 工具命令使用统一扩展 ID `0x18A050F5` 和协议版本 4；Byte0 高 4 位是版本、低 4 位是操作码，Byte1 是请求计数，固定 DLC=8。除 RTC 外均核对请求计数、命令码和主控 `0x18A650F4` 统一应答。
- 配置类命令只在自检、待机或故障保持态处理。预充和高压闭合期间由主控拒绝；充电机类型还要求退出充电模式且高压状态机空闲。
- 故障复位仍由主控检查实时告警和实体 HV_ACC 上高压请求是否已释放。上位机只发送请求，不替代主控的安全判断。

## 3. BMS 监视使用

1. 点击底部“BMS 未连接”（或已连接状态按钮）。
2. 在弹出的“BMS 主连接”弹窗中选择监视总线和 PCAN 通道。
   - 源码运行时会额外显示 `内置模拟数据 · CAN1 / 开发测试`，用于没有实体 PCAN 时的界面和协议开发；Windows 发布版不提供该项。
   - `CAN1 · F405 主控 / 从控 / 工具`：查看 138 串、48 路温度、F405 状态和发送 F405 工具命令。
   - `CANB · IVT / ECU / Chroma · 500 kbit/s`：查看 CANB 上的 BMS 状态、IVT 结果和 500 kbit/s 充电链路。
   - `CANB · Legacy / IVT · 250 kbit/s`：查看 Legacy 固定 250 kbit/s 链路。
3. 连接后先看“运行总览”的状态机、告警和关键电气量；需要定位时进入“电芯与温度”“故障与记录”或“CAN 监视器”。
4. 需要改 F405 参数时进入“参数与命令”。界面会检查 CAN1、主控状态和状态帧新鲜度，每次写入都需要再次确认。PCAN 发送成功不代表主控已经接受，最终以主控应答和周期回报为准。

主控工具命令只从 CAN1 发送。CANB 连接用于读取 CANB 数据，不用于发送 F405 主控配置命令。数据无效、报文缺失或状态帧超时时，页面显示“等待数据”，不使用 0 或旧值冒充当前结果。

RTC 校时按钮旁的状态在本次连接内持续显示最近一次校时应答和主控读回的时间；尚未校时时按主控周期上报的 RTC 有效性显示“主控 RTC 有效”或“RTC 未校时”。校时写入的是上位机本地时间，主控 Flash 日志时间戳与此同一口径。

“故障码变化记录”和 CAN 监视器的时间列使用上位机收到帧时的本机时间，不使用 PCAN 适配器内部计数；CSV 和 `.bmslog` 记录、回放显示同为这一口径。主控 Flash 故障日志的时间来自主控 RTC，与上位机接收时间无关。

## 4. 整车总览

### 连接

1. 点击底部“整车未连接”（或已连接状态按钮）。
2. 在弹出的“整车 CANB 连接”弹窗中选择 PCAN 通道和位率（整车 CANB 为 500 kbit/s），点击“连接”。
3. 源码运行时另有 `内置模拟数据 · CANB`，用于无实体 PCAN 时的整车页面开发；Windows 发布版不提供该项。
4. 底部状态栏的“整车连接”按钮显示实时通道与位率，再次点击可查看或断开连接。

### 页面内容与判定

| 卡片 | 数据来源 | 判定 |
|---|---|---|
| SOP 限功率 | `0x4A0` 限值 + `0x4A3` 状态 + `0x4A4` ECU 确认 | 配对 CRC 校验失败会标红；ECU 确认区分“已采用/未确认/ECU 故障” |
| BMS 整车镜像 | `0x4B0` 包状态 + `0x4B1` 故障 | 电压/电流/SOC 各自带有效位，无效显示“等待数据” |
| 自有 IVT-S | `0x512..0x519`（小端） | 每通道独立新鲜度；结果状态非 0 标“结果异常” |
| 赛会能量计 | `0x521/0x522/0x526/0x528`（大端） | 功率/能量两帧设备可能不发送，未收到显示“未发送” |
| PDM 低压配电 | `0x5A0` 总线侧 + `0x5A1` 电池侧 | 四字段全无效值判该路 INA226 离线；累计电量为上电累计，655.36 Wh 回绕 |
| ECU 四轮状态 | `0x502/0x505..0x509` | 扭矩 %Mn、转速、电机/逆变器/IGBT 温度按 FL/FR/RL/RR 显示；就绪/使能/故障按轮汇总 |
| 轮胎温度 | `0x071..0x074` | 每帧 4 测点（整数 + 0.01 °C 小数）；帧与轮位的对应关系待实物确认，按帧 ID 分组显示 |
| 高压/低压趋势 | 0x4B0 与 PDM 采样 | 左轴高压电压、右轴低压电压，图例同时显示两路电流 |

### 常看值快捷栏

所有非工具页在底部状态栏上方常驻一行常看值：低压电压/电流/功率（PDM 总线侧）、高压电压/电流、SOC、SOP 放电/充电功率限值、风扇最高转速。高压和 SOC 优先取 BMS 主监视连接，主连接无数据时回退整车连接的 `0x4B0`；低压、SOP 和风扇来自整车连接。任一来源无数据时该格显示“等待”，不用 0 冒充。调 F405 参数（CAN1）的同时可以在这里看 CANB 上的低压值。

### CAN 监视器数据源

CAN 监视器工具栏新增“主连接 / 整车连接”切换：主连接看 BMS 监视通道的原始帧，整车连接看 CANB 整车通道的原始帧（含新节点帧名，如 PDM `0x5A0/0x5A1`、ECU `0x502..0x509`、胎温 `0x071..0x074`）。筛选、暂停和行数限制对当前数据源生效。

## 5. 台架模拟从控

### 连接和启动

1. 展开左侧“工程工具”，进入“台架模拟从控”。
2. 选择连接 F405 CAN1 的 PCAN 通道，点击“连接”。页面固定使用 500 kbit/s。
3. 看到六个从控状态后，再开始注入场景。主上位机需要同时监视 F405 时，可以在另一个主监视连接中打开同一 CAN1；如果 PCAN 驱动拒绝第二个句柄，按提示释放占用或使用另一个 PCAN 通道。

### 页面会发送什么

台架启动后按脚本周期发送：

- 六个从控的 36 帧电压数据，合计 138 串；
- 六个从控的 6 帧温度数据，合计 48 路；
- 不发送 IVT `0x512..0x519`、充电机反馈或 IMD 报文。

六个从控默认在线，电芯和温度使用脚本中的默认值。页面下方的六个状态格用于确认从控在线情况和默认测量值。

### 注入场景

快速按钮用于常用测试。命令框接受脚本的原命令格式，例如：

```text
cell 1 3900
temp 1 40
slave 2 online off
scenario openwire on 1
```

开始下一组测试前点击“恢复默认”。需要验证 F405 真实 IVT、充电机、IMD 或 CANB 报文时，使用真实设备或对应独立工具，不在本页面伪造。

## 6. IVT 配置

### 连接前准备

1. 将 PCAN 和目标 IVT-S 接到 IVT 所在 CANB。
2. 总线上只保留目标 IVT 和 PCAN，暂时移除其他会响应 IVT 命令的节点。
3. 在页面选择 PCAN 通道和 IVT 当前位率。第一次读取出厂设备通常使用 500 kbit/s；如果设备当前用于旧 Legacy 充电机，按设备当前实际位率选择 250 kbit/s。
4. 点击“连接”。PCAN 位率必须与 IVT 当前位率一致，否则不会有有效应答。

### 先读取，再决定是否配置

点击“读取并核对”。页面会先尝试出厂地址 `Command 0x411 / Response 0x511`，再尝试 BMS 目标地址 `0x410 / 0x51A`，随后读取设备信息、当前/上电模式、8 个通道、结果帧地址和正负过流阈值。

核对结果的含义：

| 页面结果 | 含义 | 下一步 |
|---|---|---|
| 已配置且一致 | 当前配置与 F405 CANB 目标全部一致 | 可以断开配置通道，接入 F405 验证结果帧 |
| 未配置 | 读取到出厂通道、地址和关闭过流阈值 | 首次接入 F405 前执行一次 BMS CANB 配置 |
| 配置不符 | 只有部分项目一致，或存在被改过的参数 | 展开逐通道核对，确认后再配置 |

页面主区域只显示现场需要的结果。逐通道周期、格式和差异放在“查看逐通道核对”中；当前 Command/Response ID 和过流核对值放在“高级”中，通常不需要修改。

### 配置为 BMS CANB

当设备是首次安装或核对结果为“配置不符”时：

1. 确认总线仍只有目标 IVT，且 PCAN 位率与 IVT 当前位率一致。
2. 如有需要，在“高级”中填写目标上电模式和过流阈值；过流值为 0 表示关闭。
3. 点击“配置为 BMS CANB”，在确认窗口核对通道、位率和目标地址后确认。
4. 页面会停止 IVT，写入 BMS 目标配置，保存并重启 IVT，然后自动等待 Alive 和重新读取。
5. 看到“已配置且一致”后，断开 PCAN，按 BMS-MASTER-F405 仓库 `DOC/IVT能量计配置与CANB切换.md` 的步骤接入 F405 CANB。

页面会先要求完成“读取并核对”：读回前配置按钮保持禁用；如果结果已经是“已配置且一致”，配置按钮也会保持禁用，避免重复写入。

BMS 目标的现场摘要为：结果帧 `0x512..0x519`，通道格式 `0x42`（小端、周期发送、正常符号、报错位关闭），Command `0x410`，Response `0x51A`。周期和每个通道的完整字段见 IVT 文档。

### 旧 Legacy 充电机的位率切换

“旧充电机过渡”只改变 IVT 的 CAN 位率，不改变结果通道和 CAN ID：

- 旧 Legacy 充电机链路需要 250 kbit/s 时，点击“切到 250 kbit/s”；
- 回到 F405 当前 500 kbit/s CANB 链路前，点击“切到 500 kbit/s”。

点击后 IVT 会重启，上位机会关闭当前 PCAN、按目标位率重新打开并等待 Alive。切换前后的连接位率必须与设备实际位率匹配。Legacy 固定变体的安装位率由整车配置决定，运行中不反复切换。

## 7. 整车风扇

### 连接和查看状态

1. 整车风扇页使用整车连接（与整车总览共用）。点击底部“整车未连接”（或已连接状态按钮），在弹出的“整车 CANB 连接”弹窗中选择 PCAN 通道和位率后连接；也可以先在整车总览页连接，再进入本页。
2. 连接后页面按 100 ms / 500 ms 周期解析 FanController 报文：
   - `0x5A2`（100 ms）：三路实际转速与两路当前实测占空比；
   - `0x5A3`（500 ms）：目标占空比、当前模式、最高电机/控制器温度、温度输入有效位和 8 个故障位；
   - `0x5A8`（100 ms）：供电状态机（低压电池 / DCDC接管中 / DCDC就绪 / 功率受限 / 数据故障）、限功率原因、电流预算（A）与预测总线电流（A）。
3. 帧超时或温度源失联时显示“等待数据”或“失联”，不用 0 冒充读数。

### 发送命令

命令使用标准帧 `0x5A4`（DLC=8，字节 7 为 CRC-8/SAE-J1850），页面在确认窗口核对通道、位率和参数后发送，并等待 `0x5A5` 按操作码和序号应答；1 秒无应答或结果非成功时明确报错。可用命令：

| 操作 | 操作码 | 内容 | 限制 |
|---|---|---|---|
| 模式与目标占空比 | `0x01` | 自动 / 手动 / 关闭 | 手动/关闭带 1..60 秒有效时间，到期自动回自动；关闭模式两路必须为 0 |
| 回路1温控曲线 | `0x02` | 电机水套曲线五个参数 | 关闭 < 启动 < 全速 ≤ 150 ℃，占空比和速度 10..100 |
| 回路2温控曲线 | `0x06` | 逆变器/IGBT曲线五个参数 | 关闭 < 启动 < 全速 ≤ 150 ℃，占空比和速度 10..100 |
| 失联策略 | `0x03` | 策略、两路保底占空比、保持时间、下降速度 | 策略 0..2，保底 0..100%，保持 0..30 秒，下降 10..100%/s |
| 恢复默认策略 | `0x04` | 曲线 35/40/60 ℃、固定保底 50%/50%、保持 5 s | 同时回到自动模式 |
| 查询当前策略 | `0x05` | 触发回报 `0x5A6` 与 `0x5A7` | 无参数 |
| 标定会话控制 | `0x08` | 启动/续约/停止/确认DCDC就绪 | 仅限 DCDC_READY 供电；带 1..60 秒租约与过流/超温保护；电流方向已实测确认（正=放电），Action=4 用于标定前由操作者再次确认 |

温控曲线和失联策略只保存在 RAM 中，FanController 复位后恢复默认。写入成功后页面用回报值刷新输入框；修改过输入框后以页面值为准，直到发送成功或重新查询。

### 台架功率标定工作台

页面提供自动阶梯扫频标定工作台：
1. **安全前置检查**：必须满足 PCAN 在 CANB 上、PDM 总线遥测正常、供电为 `DCDC_READY` 稳态、电机温度 < 70 ℃ 且无风扇停转故障；标定前先发送 `0x08 Action=4` 由操作者显式确认；
2. **基准测量**：自动测量 0% 占空比下的低压总线静态功耗（$V_{\text{base}}, I_{\text{base}}, P_{\text{base}}$）；
3. **阶梯扫频**：按预设步长（含 5/8/10/12/15% 低占空比点，0%..100%）阶梯调节目标通道（PWM1 / PWM2），等待稳态并计算增量 $\Delta I$ (A) 与 $\Delta P$ (W)；
4. **实时安全监控**：在扫频全过程中若检测到 PDM 离线、脱离 DCDC 供电、总线过流或超温，立即触发紧急中止；
5. **数据导出**：支持一键导出 CSV 与 JSON 标定测试记录，便于拟合和填入固件预测表。

### 应答记录

页面下方显示最近的 `0x5A5` 应答：操作码、序号、结果、当前模式、失联策略和四路占空比。手动/关闭模式到期自动回自动时，FanController 会主动补发一条“模式超时，已回到自动”的应答。

## 8. 常见提示和处理

| 提示或现象 | 处理 |
|---|---|
| 等待 CAN 数据 | 检查对应连接、PCAN 通道和位率；数据无效时页面保持“等待数据”，不会用 0 或旧值代替 |
| 整车页某卡片整卡“等待数据” | 该节点没有上电或不在 CANB 上；赛会能量计的功率/能量两帧未发送属正常，显示“未发送” |
| PDM 某侧显示“INA226 离线” | 该路 INA226 无响应（四字段全无效值）；检查 PDM 供电与 I2C，见 PDM 仓库 `Doc/CAN接口.md` |
| 台架连接失败 | 检查 PEAK 驱动、PCAN 通道是否被占用，以及通道是否确实接到 F405 CAN1 |
| IVT 读取超时 | 确认 IVT 供电、当前位率和总线接线；出厂设备用 0x411/0x511，已配置设备让页面自动探测或在高级中填写当前地址 |
| IVT 配置不符 | 查看逐通道核对；确认设备确实是要接入本 F405 的 IVT 后再重新配置 |
| 切换位率后没有 Alive | 用目标位率重新连接；仍无响应时回到原位率检查设备和接线 |
| 整车风扇命令无应答 | 确认 FanController 供电、CANB 接线和位率；1 秒无 `0x5A5` 时命令不会重发 |
| 整车风扇命令被拒绝 | 查看应答记录中的结果：参数错误按命令表核对范围；CRC/长度错误一般只在总线干扰或固件不一致时出现 |
| 第二个独立连接失败 | 可能是 PCAN 驱动不允许同一通道同时打开多个句柄；先断开占用连接或换用另一个 PCAN 通道 |
| 主控命令被拒绝 | 查看“参数与命令”的主控状态、告警和应答原因；预充或高压闭合期间不要反复发送 |

故障、数据失效和状态帧超时使用不同的醒目状态。正常状态保持安静；看到“等待数据”时先处理连接或报文问题，不要按测量值为 0 继续判断车辆状态。

## 9. 验证顺序

### 软件内更新

Windows 发布版左下角的版本信息是“软件内更新”入口。程序启动时自动检查一次 `BITFSAE/can-host` 的正式 Release，也可点击左下角版本信息手动检查、下载和安装：

1. 打开“软件内更新”窗口后点击“检查更新”；勾选“包含预发布版（Pre-release）”可检查带有 `-rc1` 等后缀的预发布。
2. 点击“下载更新”，程序下载 ZIP 与对应 `.sha256`，校验 SHA256 并验证 ZIP 只包含 `BITFSAE_CAN_Host/` 目录（拒绝绝对路径、`..` 和符号链接）。
3. 校验通过后点击“退出并安装”：当前应用退出，隐藏 PowerShell 助手等待旧进程结束，将旧目录备份为 `.old-<时间戳>`，移入新目录并重新启动；新版本启动失败时自动恢复旧目录。
4. 仓库为公开时无需任何凭据；仓库为私有时在更新窗口保存只读 GitHub PAT（至少 `contents:read`），令牌只保存在本机 `%APPDATA%\BITFSAE\CAN Host\settings.json`，不返回前端、不写入日志。
5. 源码运行只能检查更新，不能替换安装目录。安装失败或新版本启动失败时旧目录保持或自动恢复，可查看安装目录同级 `install-helper.log`。

发布者操作与 CI 生成附件见 [`../README.md`](../README.md) 的“CI 自动构建与发布”和“软件内更新”两节。

### 软件和界面

1. 源码运行上位机，确认 BMS 四页、整车两页、CAN 监视器（两种数据源）和工程工具折叠项都能打开。
2. 主监视连接用内置模拟数据走一遍 BMS 页面；整车连接用内置模拟数据走一遍整车总览和风扇页，确认所有卡片有数、快捷栏九格有值。
3. 启动台架模拟从控，确认 F405 收到 138 串和 48 路数据，注入过压、欠压、温度、离线和断线场景，确认主控告警和页面状态一致。
4. 用真实 IVT 完成“读取—分类—配置—重读”流程，确认显示“已配置且一致”。
5. 连接真实 FanController，确认状态与诊断显示、五种命令的应答结果，以及手动模式到期自动回自动的补发应答。

### 实体联调

1. 先在低压、无高压输出条件下验证 PCAN 通道和位率。
2. 整车连接接实车 CANB，逐卡确认 SOP、0x4B0、IVT、PDM、ECU、胎温有真实数据；核对 IVT U1 与 BMS 包电压一致性。
3. 配置 IVT 后断开配置 PCAN，再接入 F405 CANB，检查 `0x512..0x519` 和 IVT 离线告警。
4. 旧 Legacy 链路分别验证 250 kbit/s 和回切 500 kbit/s 的 Alive、结果帧周期和 F405 接收状态。
5. F405 工具命令、故障复位、Flash 日志和高压动作按 BMS-MASTER-F405 仓库 `DOC/调试与台架测试.md` 执行；本文不重复固件内部判定规则。

项目级自动测试已覆盖从控映射、主控状态、故障与告警、工具命令编码和应答、IVT 协议与核对、CANB 写入边界、SOP/IVT/PDM/赛会能量计/ECU/胎温解码、风扇命令与应答、模拟链路和记录/回放。实体 PCAN、真实 IVT、实车 CANB 各节点、赛会能量计实际发送行为、胎温轮位映射、F405 台架、充电机、Windows 发布包和长时间记录仍需现场验证；详细检查项见 [`todo.md`](../todo.md)。
