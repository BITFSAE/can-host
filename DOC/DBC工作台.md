# DBC 工作台

本文说明“监视 → DBC 工作台”：载入 DBC 后实时解码总线、画曲线、编辑并保存 DBC、按信号发送，以及把 DBC 与总线实际情况对账。连接、记录和原始帧发送见 [`CAN上位机与工具使用.md`](CAN上位机与工具使用.md)；开发、测试和打包见 [`开发与发布.md`](开发与发布.md)。

## 1. 职责与边界

- DBC 工作台只用于查看和调试，不驱动任何页面状态机，也不进入底栏常看值。BMS、整车、风扇和台架页面仍只认 `canhost/decoders.py`，两处定义不得互相替代。
- 它不拥有 CAN 连接，也不打开总线：解码读的是 CAN 监视器已经收到的帧，曲线与对账由接收线程上的只读观察者记录。发送只生成数据，真正下发沿用监视器的原始帧发送，确认弹窗、受保护 ID 拒绝和“模拟与回放不可写”全部照旧。
- 整车 DBC 的权威位置在 `../vehicle-interfaces/can/`，固件与 DBC 不一致时以固件为准。位于 `vehicle-interfaces` 目录下的 DBC 默认只读，要改动中央库本身，走该仓库的校验与提交流程；在上位机里改动时先“另存为”副本。

## 2. 文件与总线绑定

主导航的折叠按钮可在文字导航和图标导航之间切换，选择会保存在本机。工作台的“目录”按钮单独收起文件与报文列表，也会记住状态。窄窗口用抽屉显示目录，选中报文后自动收起；页签与底栏保持可见，报文列表和右侧内容分别滚动。

报文筛选支持名称、ID 和信号名，并显示匹配数量。点清除按钮或按 `Esc` 恢复列表。列表中可用上下方向键、`Home` 和 `End` 选择报文；功能页签可用左右方向键切换。

切换文件会清除上一文件的筛选和复用视图，并回到内容顶部。迟到的目录或状态请求不会覆盖当前文件的选择。

1. 点“打开 DBC”、把 `.dbc` 拖进窗口，或在没有文件时点“团队中央库”里的按钮（源码运行且存在同级 `vehicle-interfaces` 时才有）。最多同时打开 12 个。
2. 每个文件卡的下拉决定它解码哪条总线：`CAN1`、`CANB`、`全部总线` 或 `不解码`。文件名含 `can1` / `canb` 时自动选对应总线，其他文件默认不解码。
3. 页面顶部的 `CAN1 / CANB` 选择要看的数据流。主连接接 CANB（Legacy 或回放 CANB 记录）时按 CANB 绑定解码，回放按记录里的总线档案。
4. 同一总线上有多个 DBC 含同一 ID（标准帧与扩展帧分开计）时，先载入的文件生效，文件卡下方提示重复个数。
5. 已打开的文件、绑定、观察表、曲线选择和数据源保存在用户设置里，下次启动自动恢复；找不到的文件提示后跳过。
6. 文件被外部改动后文件卡出现“重新载入”；未保存的修改在关闭文件时会先确认。

CANA、CANC 等文件都可载入、查看和编辑，中央库文件仍需先另存为。当前接收源只有主连接与整车连接，顶部 CAN1/CANB 表示这两路接收源，不是可打开的 DBC 文件种类。CANA/CANC 默认“不解码”，页面显示“仅查看，尚未绑定接收数据流”；要实时解码，先让对应接收连接收到该总线的帧，再通过“选择数据流”定位文件卡，手动设置绑定。载入文件不会新增或切换实体连接。

## 3. 实时解码

选中左侧报文，“实时”页给出最新一帧的解码：

| 显示 | 含义 |
|---|---|
| 报文标签 `等待数据` | 连接后一帧也没收到；信号值显示“等待数据”，不会显示 0 |
| `实时` / `已过期 N s` | 距最新帧超过 `max(2 s, 3 × 周期)` 即过期，周期取实测，没有实测取 DBC 周期；过期后保留最后一帧并标黄 |
| `DLC 不符` | 收到的字节数少于 DBC 长度；只解码完整落在已收字节内的信号，其余显示“DLC 不足”，不补零 |
| 信号 `未生效` | 多路复用选择值不在该信号的分支，本帧没有它的数据 |
| 含义列 | 值表文字；值不在值表里显示“表外值” |
| 红色数值 / 范围条 | 超出 DBC 声明的 `[最小\|最大]` |

每个信号同时给物理值（带单位）、原始值（十进制与十六进制，64 位原始值以文本传输不丢精度）和范围条。回放时年龄按回放时钟计算，不会因记录是旧数据而全部显示过期。

- **观察表**：在信号行点“观察”，跨报文的信号汇总在一起；只显示当前数据源的项。
- **未识别帧**：总线上有、已绑定 DBC 里没有的 ID，显示数据、周期和帧数；点“建模”用该帧的 ID、DLC 和实测周期预填新建报文。
- **监视器页**：已绑定 DBC 的帧在注释列显示 DBC 报文名（内置名未登记时直接替换），点 `Σ` 在行下展开解码出的信号。

## 4. 曲线

在“实时”页点信号行的“曲线”加入，最多 24 条。

- **实时**：后端逐帧记录订阅的信号（每个数据源每条 12 万个样本的环形缓冲），页面按游标增量取回，界面刷新间隔不影响采样密度。窗口可选 10 s、30 s、1 min、5 min 或全部；拖选放大会自动冻结；`归一化` 把每条曲线按自身范围画到 0–100%；不同单位分左右轴，超过 3 种单位自动归一化。可清除、导出所见样本为 CSV。
- **记录文件**：“打开记录”读取 `.bmslog` 或 CSV，整段解码而不用回放（`.bmslog` 按 `(ID, 时间)` 索引直接查询；CSV 上限 200 万帧）。曲线按最多 6000 点抽稀并保留每段的极值，尖峰不会被抹掉；右侧选择用 CAN1 还是 CANB 的绑定；“按 DBC 导出全部信号”写出长表 CSV（时间、报文、ID、信号、原始值、物理值、单位、值表）。

## 5. 编辑

编辑区依次显示报文属性与位布局、完整信号表、所选信号属性。区域随可用宽度排列，长信号名允许换行。只读文件也能点击位格或信号名查看属性，修改控件保持禁用。

Vector 的 `VECTOR__INDEPENDENT_SIG_MSG` 显示为“未使用信号”，保留信号列表和属性查看，不画报文位图；这些信号尚未分配到报文，不能用于实时观察或曲线。

“编辑”页的改动立即写入保真文档并热更新解码：改完去“实时”页就能验证，“当前帧试算”直接显示所选信号在最新一帧里的原始值和物理值。

- **报文与信号**：名称、ID（标准/扩展自动处理）、DLC、发送节点、周期、注释；信号的位置、长度、字节序、符号、数值类型（整数/float32/float64）、因子、偏移、范围、单位、接收节点、多路复用（选择信号、`mN`、扩展复用的父信号与取值范围）、初始原始值、注释和值表（可套用全局值表）。新建、复制、删除、上移、下移。
- **位布局**：点格子选信号；拖选设置所选信号的位置，没有选中信号时拖选新建一个。Intel 按位序连续，Motorola 沿“字节内从高到低、再进下一字节”连续。红格重叠，虚线格在 DLC 之外。新建信号用的字节序在位图上方切换。
- **节点、全局值表、属性定义、版本与数据库注释**各有一页；重命名会同步所有引用（发送者、接收者、注释、属性、值表）。
- **校验**：重叠、越出 DLC、名称不合法或重复、ID 重复、长度或浮点长度错误、因子为 0、最小值大于最大值、值表取值超出位宽、被复用信号没有选择信号、发送/接收节点未定义，以及范围超出原始值能表示的区间等；错误会阻止保存。没有周期、含中文需用 GBK 保存等只是提示。
- **对比**：编辑栏的“对比”列出另一个已打开的 DBC 相对当前文件的新增、删除和修改（例如中央库与自己的副本），同样给出语义变化和文本差异，不修改任何文件。
- **撤销 / 重做**最多 100 步；`Ctrl+S` 保存，输入框之外 `Ctrl+Z` / `Ctrl+Y` 撤销重做。

### 保存

- 保存只改动被编辑的语句：未编辑的行、Vector 的 `VECTOR__INDEPENDENT_SIG_MSG`、换行风格和段落顺序逐字节不变。重命名与改 ID 会同步所有引用。
- 保存前要求无校验错误，并且生成的文本通过 cantools 严格解析；写入先写临时文件再替换，旧内容留在 `<文件>.bak`。
- 编码保持文件原来的（UTF-8、UTF-8 带 BOM 或 GBK）；所选编码无法表示的字符直接拒绝，不替换。
- “评审变更”列出新增、删除、修改的报文和信号及字段前后值，并给出文本差异；评审里可选 **CANdb++ 规整保存**（按 CANdb++ 要求重排段落、注释合并为单行、补 `Vector__XXX`，默认 GBK + CRLF）和保存编码。规整后会再核对语义，有差异时提示。
- 名称超过 32 个字符时按 CANdb++ 约定写入前 32 个字符并在 `SystemSignalLongSymbol` / `SystemMessageLongSymbol` / `SystemNodeLongSymbol` 里保存全名；读取时同样还原全名。

## 6. 按信号发送

“发送”页只列出当前文件在所选接收源中生效的报文，逐个信号填物理值（有值表的用下拉），页面实时显示将发送的字节。未绑定文件或被其他文件同 ID 覆盖的报文不会借用其他文件的发送表单。

- 取值超出原始位宽会被拒绝；超出 DBC 声明的 `[最小|最大]` 允许，台架可以测试越界行为。没填的信号用初始值或 0。
- “发送一次”与“启用周期发送”（20..60000 ms）都先弹出和监视器相同的确认；受保护的命令 ID 被后端拒绝，需要用对应专用页面发送；模拟和回放不可写。
- 周期发送运行中锁定信号值、周期和恢复初值按钮。先停止，再修改并重新确认。停止操作只依赖任务标识，编码失败时也能停止。

修改信号值后，旧编码预览立即失效，编码完成前禁用发送。快速连续输入、切换报文或数据源时，过时的编码结果会被忽略。

## 7. 对账

“对账”页把 DBC 与总线实际情况逐项对照，实时统计或对账一个记录文件：

| 项目 | 判定 |
|---|---|
| 总线上有、DBC 里没有 | 统计窗口内出现了 DBC 没定义的 ID |
| DBC 里有、没出现 | 统计窗口不少于 3 秒后才判断 |
| DLC 不一致 | 出现过与 DBC 长度不同的帧 |
| 周期不一致 | 实测均值与 `GenMsgCycleTime` 相差超过 20% 且超过 5 ms（至少 5 个间隔） |
| 取值越界 | 解码值超出 DBC 声明的范围 |
| 取值不在值表 | 有值表的信号收到表外的值 |

切换 CAN1/CANB 时，先清除上一数据源的报告，再读取当前源的统计，迟到的旧请求不会覆盖当前页面。

固件与 DBC 不一致时以固件为准，这一页提供证据，不自动改任何文件。

## 8. 接口

页面通过 `dbc_*` 接口使用后端（`canhost/dbc/api.py`），全部返回 `{ok, ...}`，输入有长度和类型校验。

| 接口 | 用途 |
|---|---|
| `dbc_state` / `dbc_set_view` | 文件列表、恢复与保存观察表和曲线选择 |
| `dbc_choose_open` / `dbc_open` / `dbc_new` / `dbc_close` / `dbc_reload` / `dbc_set_bus` | 文件管理与总线绑定 |
| `dbc_detail` | 一个文件的目录（节点、报文、信号、值表、属性）和校验结果 |
| `dbc_edit` / `dbc_undo` / `dbc_redo` | 一批原子编辑与历史 |
| `dbc_save_review` / `dbc_save` / `dbc_choose_save` / `dbc_compare` | 评审、保存、另存为和两个已打开 DBC 的差异对比 |
| `dbc_live` | 最新帧解码、报文摘要、未识别帧和重复 ID |
| `dbc_series_set` / `dbc_series_fetch` / `dbc_series_clear` | 实时曲线订阅与增量取回 |
| `dbc_audit` | 实时对账：开始、停止、重置、取报告 |
| `dbc_form` / `dbc_encode` | 按信号发送的初值和编码；发送仍走原始帧接口 |
| `dbc_trace_choose` / `dbc_trace_series` / `dbc_trace_audit` / `dbc_trace_export` / `dbc_trace_close` | 记录文件曲线、对账和导出 |
| `dbc_save_text` | 保存页面生成的文本（曲线 CSV） |

编辑操作是 JSON：`add_message`、`set_message`、`delete_message`、`duplicate_message`、`move_message`、`add_signal`、`set_signal`、`delete_signal`、`duplicate_signal`、`move_signal`、`set_choices`、`add_node`、`rename_node`、`delete_node`、`set_comment`、`set_value_table`、`set_attr_def`、`delete_attr_def`、`set_attr_value`、`set_version`。多条操作一起提交时任一条失败则全部回退。

## 9. 异常处理

| 现象 | 检查 |
|---|---|
| 报文一直“等待数据” | 该 DBC 是否绑定到当前数据源的总线；数据源对应的连接是否在线；ID 的标准/扩展类型是否与 DBC 一致 |
| 文件卡显示“非当前总线” | 在文件卡下拉里选当前总线，或切换页面顶部的 CAN1/CANB |
| “DLC 不符” | 固件实际发送长度与 DBC 不同；到“对账”页确认，以固件为准修 DBC |
| 保存被拒绝并跳到“校验” | 修正列出的错误；重叠的信号可拖到空位 |
| 保存提示字符无法用 GBK 保存 | 改用 UTF-8，或去掉该字符 |
| CANdb++ 打不开 | 用“CANdb++ 规整保存”（GBK + 段落顺序）；打开新保存的文件而不是刷新旧窗口 |
| 编辑被拒绝“只读” | 中央库 DBC：另存为副本后编辑 |
| 曲线没有数据 | 先在“实时”页确认信号有值；记录文件曲线要选对 CAN1/CANB 绑定 |
| 对账报“周期不一致”但硬件正常 | 核对 DBC 的 `GenMsgCycleTime`；0 表示非周期，不参与对账 |

## 10. 调试与验证

- 单元测试：`Tests/test_dbc_document.py`（保真读写、编辑操作、CANdb++ 文本）、`test_dbc_decode.py`（解码、位布局对照 cantools 编码器）、`test_dbc_workspace.py`（文件、历史、保存、实时、曲线、对账、记录文件）、`test_dbc_api.py`（接口与接收链路）、`test_dbc_ui.py` 与 `Tests/dbc_ui_smoke.js`（页面接线、位布局与后端逐位一致、显示规则）。存在同级 `vehicle-interfaces` 时，另有四份团队 DBC 的字节级往返与解码测试。
- 交互回归：`Tests/dbc_interaction_smoke.js` 验证导航状态记忆、存储不可用时的导航、只读位图选择、编码请求过时失效、对账数据源隔离、文件切换与请求乱序、未使用信号呈现和发送表单文件隔离，由 `test_dbc_ui.py` 执行。
- 无硬件看界面：`scripts/ui_preview.py` 把 DBC 接口转发到连着内置模拟通道的真实后端，载入中央库 DBC 即可看到真实的解码、曲线、编辑和对账；预览时用 `XDG_CONFIG_HOME` 指向临时目录，避免改动真实用户设置。
- 实体验证：把中央库 DBC 绑定到对应总线，在实车或台架上先看“对账”，再逐条核对关键信号；本页的解码不能替代对固件的核对。

## 11. 待确认与已知不足

- 拖入文件和系统文件对话框在 Windows WebView2 与 macOS WKWebView 的表现尚待实机核对；打开按钮始终可用。
- 只支持经典 CAN（DLC 0..8）；含 CAN FD 报文的 DBC 可载入和解码，校验会提示。
- 环境变量、信号组、关系属性等语句被保留但没有编辑界面；J1939 / GMLAN 匹配、KCD/SYM/ARXML 导入未实现。
- 尚未做“DBC 与 `decoders.py` 逐帧一致性检查”，固件、DBC 与上位机三方的一致性目前靠对账页和既有协议测试分别保证。
